# Bilder av ferdig bygg

Legg bilder og videoer her etter hvert som bilen bygges.

## Navngiving

```
2026-11-22_chassis-ferdig.jpg
2026-11-23_foraksel-montert.jpg
2026-11-24_full-bil-forfra.jpg
2026-11-24_forste-tur.mp4
```

Format: `ÅÅÅÅ-MM-DD_kort-beskrivelse.ext`

## Hva det er lurt å ta bilde av

- Chassis rett etter print (kontroller at ribber og hull er fine)
- Testplaten med skyvelære ved siden av (dokumenterer toleransene)
- Hver monteringsfase: armer → spindler → motorer → styring → elektronikk
- FPV-oppsett: kamera, gimbal, antenneplassering
- Første tur og range-test
- Skader/feil (nyttig for å forbedre designet)

## Tips

- Ta bilder i godt lys, gjerne med målestokk (linjal eller A4-ark) i bildet
- Film korte klipp av bevegelser (styring, fjæring) – nyttig for å verifisere geometrien
- Legg gjerne til en kort kommentar i `print-logg.md` om hva bildet viser
